How to Use

How to Generate Meta Tags

Meta tags help search engines and social platforms understand your page. This generator creates basic SEO, Open Graph, and Twitter card tags.

  1. Enter your site name, page title, description, URL, and image URL.
  2. Choose the robots directive for the page.

  4. Copy the generated code and paste it inside your page head tag.

FAQ

Meta Tags Generator FAQs

Common questions about SEO meta tags, Open Graph, Twitter cards, and canonical URLs.

What are meta tags?

Meta tags are HTML tags placed inside the head section of a page. They describe the page to search engines, browsers, and social platforms.

What is a meta description?

A meta description is a short summary of a page. Search engines may show it as a snippet under the page title.

What are Open Graph tags?

Open Graph tags control how your page appears when shared on social platforms like Facebook, LinkedIn, and other apps.

What is a canonical URL?

A canonical URL tells search engines which version of a page is the main preferred version.
