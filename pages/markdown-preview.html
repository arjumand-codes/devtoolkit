Markdown Cheat Sheet

Common Markdown Syntax

Use these quick examples while writing README files, docs, and notes.

Heading # Main Heading Creates an H1 heading.
Bold Text **Bold text** Makes text bold.
Link [Visit Site](https://example.com) Creates a clickable link.
Image ![Alt text](image.png) Adds an image.
List - First item
- Second item Creates a bullet list.
Code `inline code` Creates inline code text.
